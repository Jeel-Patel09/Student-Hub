# Integrated administrator module

This directory is the Practical 14 administrator dashboard integrated into the final StudentHub portal.

- It uses the shared `studenthub_final_db` database through `api/db.php`.
- Import only `../database/studenthub_final_setup.sql` from the project root for the final application.
- Do not import the archived Practical 14 SQL file for this integrated module.
- Sign in with the main StudentHub login or open `login.php` directly.
- Demo admin account: `admin@example.com` / `password` (local demo only; change before public deployment).
