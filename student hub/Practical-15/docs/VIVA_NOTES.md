# Practical 15 — Viva Quick Notes

1. **What is integration testing?** Testing whether the application's modules work together as one system.
2. **Why use PHP sessions?** To maintain a signed-in user's state across requests.
3. **Why hash passwords?** To avoid storing plain-text passwords in the database.
4. **What is a prepared statement?** A parameterized query that separates SQL structure from user-supplied values.
5. **What is CSRF?** Cross-Site Request Forgery; a malicious site tricks a signed-in browser into submitting an unwanted request.
6. **What is role-based access control?** Permissions are granted according to a user's role, such as student or admin.
7. **What is AJAX?** Browser JavaScript communicates with the server in the background without a full page reload.
8. **What is the purpose of an audit log?** To record important actions for review and accountability.
9. **Why use a SQL dump?** To recreate the database schema and seed data in another environment.
10. **What is a virtual host?** An Apache configuration that maps a local or domain name to a specific site directory.
11. **Why test accessibility?** So people can navigate and use the site with keyboards, assistive technology and different screen sizes.
12. **What should never be committed to GitHub?** Real passwords, private keys, production credentials, server logs or private user data.
